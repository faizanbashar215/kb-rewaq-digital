## What's in this repo
| File | Use |
|------|-----|
| `index.html` | Main bilingual landing page (auto-detects phone language) |
| `poster-generator.html` | Offline poster maker (Arabic/English, PNG copy) |
| `invoice-generator.html` | KWD invoice/bill generator |

| `samples/` | Demo sites: restaurant, salon, real estate |
| `GUIDES.md` | WhatsApp auto-reply + Talabat setup guides |
| `OUTREACH.md` | Bilingual client outreach scripts |

## Deploy
Run `deploy-github.bat` (needs a free GitHub token). Site goes live at
`https://<user>.github.io/kb-rewaq-digital/`.

All tools run offline (no server needed). Host anywhere: GitHub Pages, Netlify,
or just open the HTML files directly.
